# Install

Aztra's Forever UI is for the **WoW TBC Classic 2.5.3 (build 42328)** client only.

1. Close the game (or stay logged in and `/reload` at step 4).
2. Download the zip of the addon and extract it.
3. Copy the `AztraForeverUI` folder (the one that contains `AztraForeverUI.toc`) to
   `World of Warcraft\_classic_\Interface\AddOns\`
4. Start the game, or type `/reload`.
5. On the character screen, open **AddOns** and make sure **Aztra's Forever UI** is ticked. Turn off other action bar or bag addons (Bartender4, Dominos, ElvUI, Tukui, Bagnon, ...) for that character.
6. In game, follow the welcome window (recommended UI scale, nameplates), then type `/afui` for settings or `/editmode` to move the HUD.

Update: delete the old `AztraForeverUI` folder, copy the new one, `/reload`. Your layouts and settings stay in your WTF folder.

Uninstall: delete the `AztraForeverUI` folder. (Optional: delete `AztraForeverUI.lua` from `WTF\Account\<ACCOUNT>\SavedVariables` and the character folders to remove saved layouts.)

Problems: `/afui help` lists every command. `/afui about` prints where to reach the author.
